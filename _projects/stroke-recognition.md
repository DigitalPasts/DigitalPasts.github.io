An OCR model for recognizing cuneiform signs from 2D or 3D images is one of the biggest *desiderata* for assyriology in the 21st century. We developed an OCR model for recognizing horizontal strokes of cuneiform signs from 2D images of tablets. Cuneiform signs are created by different combination of a limited number of strokes: horizontals, verticals, obliques. This work was a first step in establishing a pipeline for cuneiform OCR from 2D images. The model is able to create a vectorized hand-copy, which will be easier for further OCR applications.
